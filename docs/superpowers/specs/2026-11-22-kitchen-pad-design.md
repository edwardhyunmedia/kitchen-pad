# 주방 홈패드 웹앱 설계 (2026-11-22)

## 목적
주방에 둔 LineageOS 태블릿(Fully Kiosk로 웹 열기)에서 부부가 같이 보는 전용 앱 모음. 앱을 계속 늘려갈 예정.

## 목표
- 홈 화면(앱 아이콘 모음) + 첫 앱 2개: 약 복용 기록, 드립커피 레시피·타이머
- 약: 약마다 정한 시간에 알람, 시간이 지나도 체크 안 되면 다시 알림
- 기록은 주방 화면에서만, 태블릿 안에만 저장

## 하지 않을 것
- 폰 연동, 계정, 서버, 외부 저장소
- 손 젖은 상태 대응(필요 없다고 함)

## 실패로 보는 것
- 기록이나 사용자 데이터가 태블릿 밖으로 나감
- 알람이 조용히 안 울림

## 방식 (검토한 3가지)
1. GitHub Pages 무료 호스팅 — **선택.** 수정 쉬움, 오프라인 캐시 가능. 코드만 공개 주소에 올라가고 기록은 안 올라감.
2. 태블릿 내부 파일 — 완전 오프라인이지만 수정마다 USB 작업 필요.
3. 맥북 서버 — 맥북 꺼지면 멈춤, 알람 용도에 부적합.

## 정해진 것 (사용자 결정)
- 웹 기반, GitHub Pages(무료)
- 기록은 태블릿 안에만
- 약: 정시 알람 + 놓치면 재알림

## Claude가 정한 것 (수정 가능)
- 구조: 빌드 도구 없는 순수 HTML/CSS/JS, 앱마다 폴더 하나 (`/meds`, `/coffee`), 홈은 `/`
- 저장: 브라우저 localStorage (태블릿 안)
- 외부 요청 0개: 폰트·라이브러리 CDN 안 씀, 분석/추적 없음
- 오프라인: 서비스워커로 캐시
- 검색 차단: robots.txt + noindex 메타. 저장소 이름은 평범하게(kitchen-pad), 코드·설명에 개인정보 없음
- 공개 범위 확인됨: 주소 알면 누구나 빈 앱은 볼 수 있음 — 사용자 동의 (도메인 구매·Cloudflare Access 잠금은 검토 후 제외)
- 약 화면: 사람별 칸(나/아내), 약마다 하루 횟수만큼 체크 버튼, 누르면 시각 기록, 다시 누르면 취소. 약·시간·사람은 앱 안 설정에서 추가/수정
- 알림: 정시에 알람음 + 화면 배너, 30분 지나도 미체크면 다시 알람(간격은 설정 가능). 알람은 "확인"을 누를 때까지 반복
- Fully Kiosk Plus 기능(화면 켜기, 음성 안내)은 있으면 쓰고, 없어도 동작(화면 항상 켜짐 + 웹 소리)
- 커피: 레시피 목록 → 선택 → 단계별 큰 타이머(뜸 → 1차 → 2차…), 단계 바뀔 때 소리. 기본 레시피 2개 넣어두고 앱 안에서 추가/수정
- 화면: 가로·세로 모두 대응, 큰 글씨, 아이콘 버튼은 정사각형

## 사용자가 할 일
- GitHub 가입·로그인(무료), 저장소 만들 권한
- 태블릿 Fully Kiosk 시작 주소를 GitHub Pages 주소로 설정, 소리 자동재생 허용
