# kitchen-pad

주방 태블릿(Fully Kiosk)용 홈뷰 스타일 개인 앱.

- 메인: 시계 페이스 7종(길게 눌러 바꾸기) → 터치하면 앱·위젯 화면, 길게 눌러 배치 편집
- 약: 사람별 복용 체크, 정시 알람, 안 먹으면 다시 알림
- 커피: 드립 레시피 단계별 타이머(다른 화면으로 가도 계속, 아래 알약 표시)
- 설정: 배경 사진, 시계 모양, 날씨, 시계로 돌아가는 시간

데이터(약 기록, 배치, 배경 사진)는 전부 그 기기 브라우저 안에만 저장.
외부 요청은 두 가지뿐이고 둘 다 설정에서 켰을 때만:
- 날씨: Open-Meteo로 고정 좌표(마포구)만 보냄
- 구글 캘린더: 내 구글 계정의 Apps Script 주소에서 7일 치 일정을 읽기만 함 (주소·비밀 열쇠는 태블릿 안에만 저장, 저장소에 없음)

배포할 때는 `sw.js`의 `VERSION` 숫자 올리기. 테스트: `npm test`
